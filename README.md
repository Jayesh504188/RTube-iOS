# RTube — Browse, Play & Cast

RTube is an all-in-one browser for video websites (React Native + Expo, iOS):

- **Home** — search pill ("Search on Google or enter website"), video-site
  shortcuts (YouTube, Twitch, TikTok, Rumble), Settings card, recently watched.
- **Browser** — full-screen, chromeless web view with:
  - invisible ad blocking (ads are skipped/muted before they render — no black
    screens, no overlays; cosmetic filter hides banners and "Open App" prompts),
  - background audio playback,
  - AirPlay cast button (native `AVRoutePickerView`),
  - auto-hiding floating toolbar (back / forward / reload / AirPlay / download / menu),
  - swipe-back gesture support.
- **History** — visited pages, per-item delete, clear all.
- **Downloads** — download direct video files from pages, in-app player, delete.
- **Settings** — Appearance (Auto/Light/Dark), Quality (Mobile Data/Wi-Fi),
  Sleep Timer (stops playback, live countdown), Background Play, Block Ads,
  Clear History, Clear Data, Language (English), Notifications (download alerts),
  Privacy Policy, Terms of Use, Contact Us, Share App, Rate App, Version.

All UI text is in English. Branding, icon, and artwork are original.

## Project layout

```
App.js                    entry: providers + navigation (tabs + stack)
app.json                  Expo config (bundle id com.jayesh504188.rtube)
src/
  adblock.js              injected JS: invisible ad-skip + cosmetic filter +
                          background-play visibility hack
  settings.js             AsyncStorage-backed preferences
  theme.js                light/dark theme hook
  history.js              browsing history store
  sleeptimer.js           countdown that pauses page media on fire
  downloads.js            expo-file-system helpers
  screens/                Home, Browser, History, Downloads, Settings,
                          SleepTimer, Info (privacy/terms), VideoPlayer
modules/
  rtube-airplay/          local Expo module: native AVRoutePickerView button
assets/                   icon.png, splash.png (original artwork)
codemagic.yaml            cloud build: prebuild -> pods -> ipa -> TestFlight
```

The native `ios/` folder is generated by `expo prebuild` and is NOT committed
(see `.gitignore`).

## Key technical decisions

- **Ad blocking is JS-only** (no `WKContentRuleList`). `react-native-webview`
  injects the script before content loads; a `requestAnimationFrame` loop mutes
  and seeks YouTube ads to their end in the same frame, clicks skip buttons,
  and CSS hides ad containers/banners. The Block Ads toggle flips a page flag
  live without reloading. This is the same approach proven in the PTUBE app.
- **AirPlay** is a tiny local Expo module (`modules/rtube-airplay`) wrapping
  `AVRoutePickerView` via `expo-modules-core` — no third-party dependency
  (the public `react-native-airplay-button` package is unmaintained since 2022).
- **Background audio**: `expo-av` audio mode (`staysActiveInBackground`) +
  `UIBackgroundModes: audio` + a page-visibility hack in the injected JS.
- **Sleep timer** pauses page media by injecting JS into the registered WebView.
- **Quality (Mobile Data)**: best-effort — appends YouTube's `vq=tiny`
  parameter on watch pages. YouTube may still adapt on its own.
- **Privacy manifest**: generated by Expo during prebuild; no data is
  collected (see in-app Privacy Policy).

## Version checklist

- Bump `expo.version` in `app.json` for App Store releases.
- Set `APP_STORE_ID` in `src/screens/SettingsScreen.js` once the App Store
  listing exists (enables the Rate App button).
- Replace `SUPPORT_EMAIL` in `src/screens/SettingsScreen.js` and the
  `support@rtube.app` mentions in `src/screens/InfoScreen.js` with the real
  support address.
